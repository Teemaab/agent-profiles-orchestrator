# Exemple : Campagne Meta Ads pour un SaaS

## La question

> "Cree une campagne Meta Ads pour mon SaaS de facturation. Cible : PME. Budget : 3000€/mois."

## Le flux

### 1. Router
Mots-cles detectes : "campagne", "Meta Ads", "SaaS", "PME", "budget" → **Profil Marketing** (principal) + **Profil Business** (secondaire pour le budget).

### 2. Profile Loader
- Charge `memory.md` du profil Marketing (projet : Facturo, cible : PME, budget : 3000€/mois)
- Charge `EXPERTS.md` du profil Marketing

### 3. Supervisor
Mots-cles : "cree", "campagne" → criticite **High** (5 skills max, Producer-Reviewer recommande).

### 4. Expert Pool
- Expert **Acquisition** → Tres pertinent (mots-cles : Meta Ads, campagne)
- Expert **Conversion** → Pertinent (mots-cles : SaaS, PME)
- Expert **Content & SEO** → Secondaire

### 5. Skills selectionnes
- `content-strategy` (Acquisition) — structure de campagne, ciblage, messages cles
- `copywriting` (Content & SEO) — textes d'annonce, accroches
- `launch` (Conversion) — page de destination et sequence de lancement
- `seo-audit` (Content & SEO — backup, si besoin de mots-cles organiques)

### 6. Producer-Reviewer
- **Producer** genere la campagne : audiences, textes, visuels suggeres, budget reparti.
- **Reviewer** verifie :
  - Le copy est-il clair ? CTA present ?
  - Le budget 3000€ est-il respecte dans la repartition ?
  - La cible PME est-elle bien definie (interets, comportements) ?
- Validation OK.

### 7. Sanity Check
- Cohérence noms : le SaaS mentionne dans la reponse est bien "Facturo" ?
- Cohérence chiffres : le budget 3000€/mois est respecte ?
- Cohérence audience : la cible est bien PME (pas grand public) ?

### 8. Resultat
Campagne Meta Ads complete :
- Objectif : Conversions (essai gratuit)
- Audience 1 : PME comptables (interets : QuickBooks, Sage)
- Audience 2 : Entrepreneurs fraichement crees (comportements : admin de page)
- Budget : 3000€/mois (60% audience 1, 40% audience 2)
- Textes d'annonce : 3 variants avec accroches testees
- Landing page : structure suggeree avec CTA "Essai gratuit 14 jours"
- Calendrier : semaine 1 (test), semaine 2-4 (optimisation)

Pas de melange avec du code ou de la strategie business. Purement marketing.
